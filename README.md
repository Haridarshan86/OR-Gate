A simple implementation of a 2-input OR Gate using Verilog HDL along with a testbench for simulation and verification.

📌 Project Overview

This project demonstrates the design and simulation of a basic OR gate in Verilog.

It is useful for beginners learning:

Verilog HDL
Digital Logic Design
Vivado Simulation
Testbench Writing
Gate-Level Verification
